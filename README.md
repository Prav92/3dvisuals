# NEXUS Fulfillment Observatory

Run `npm start` from this directory and open http://127.0.0.1:4173. Run `npm run check` for syntax validation.

A dependency-free Canvas simulation using orthographic 3D projection. Drag to rotate, scroll to zoom, select zones or dock bays, adjust efficiency, and pause or accelerate at 1x / 10x / 60x. All operational metrics are simulated. Google Fonts are optional, with system font fallbacks.
